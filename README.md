# 💊 약 먹었슈

아침·저녁 약을 먹었는지 큰 버튼 하나로 기록하는 스티커 판 위젯입니다. (개발했슈 2기 3주차 · 아빅슈크림)

- 「아침 먹었슈」「저녁 먹었슈」 버튼을 누르면 오늘 칸에 스티커(☀️/🌙)가 붙습니다.
- 하루 두 번 다 먹으면 이달 스티커 판에 🍰가 채워지고 연속 일수가 보입니다.
- 잘못 눌렀으면 「잘못 눌렀어요」로 되돌립니다.
- 기록은 이 기기 브라우저(localStorage)에만 저장됩니다. 서버로 보내지 않습니다.
