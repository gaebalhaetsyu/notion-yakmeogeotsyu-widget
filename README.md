# 약 먹었슈

먹은 약을 큰 버튼 하나로 기록하고 스티커로 붙이는 노션 위젯입니다. (개발했슈 2기 3주차, 아뱅슈크림) · 지금 버전 v1.1

배포 주소(노션 /임베드에 붙이기): https://gaebalhaetsyu.github.io/notion-yakmeogeotsyu-widget/

## 왜 만들었나

약을 먹었는지 자주 잊어서, 아예 안 먹고 하루가 지나가는 일이 많았습니다. 휴대폰에서 바로 보이고, 누르기만 하면 기록되는 것이 필요했습니다.

## 할 수 있는 것

- 「약 시간 설정」에서 아침·점심·저녁·자기 전 가운데 먹는 약만 골라 시각을 정합니다. 고른 약만 버튼으로 나옵니다.
- 「아침 약 먹었슈」 버튼을 누르면 오늘 칸에 스티커와 누른 시각이 붙습니다. 여러 번 눌러도 스티커는 하나만 붙습니다.
- 먹은 버튼을 다시 누르면 「스티커 뗄까요?」가 나오고, 「떼기」로 되돌리거나 「그대로」 둘 수 있습니다.
- 정한 시각이 지났는데 안 눌렀으면 버튼이 빨간 테두리로 바뀌고 「아침 약 아직이에요!」라고 알려 줍니다.
- 고른 약을 다 먹은 날은 이번 주 칸과 이달 판에 「다 먹은 날」 스티커가 붙고, 며칠 이어졌는지 보입니다. 달력은 일요일부터 시작합니다.
- 기록과 설정은 이 기기 브라우저(localStorage)에 저장됩니다. 저장이 막힌 브라우저에서는 안내 문구가 뜹니다.
- (v1.1) 원하면 내 노션 표에도 기록을 남길 수 있습니다. 연결해 두면 휴대폰과 컴퓨터에서 같은 기록이 보입니다. 연결하지 않으면 어디로도 보내지 않습니다.

## 사용법

### 노션에 임베드하기

1. 노션 페이지에서 `/임베드`를 입력합니다.
2. 위 배포 주소를 붙여 넣고 「링크 임베드」를 누릅니다.
3. 위젯 모서리를 끌어 크기를 맞춥니다. 휴대폰 노션 앱에서도 같은 페이지를 열면 바로 보입니다.

### 약 시간 설정

1. 오른쪽 위 「⏰ 약 시간 설정」을 누릅니다.
2. 아침·점심·저녁·자기 전 가운데 먹는 약에 체크하고 시각을 고릅니다. 체크한 약만 버튼으로 나옵니다.
3. 「저장」을 누릅니다. 설정은 언제든 다시 바꿀 수 있습니다.

약을 먹으면 「아침 약 먹었슈」처럼 해당 버튼을 누릅니다. 오늘 칸에 스티커와 누른 시각이 붙습니다. 정한 시각이 지났는데 안 눌렀으면 버튼이 빨간 테두리로 바뀌고 맨 위에 알림 띠가 뜹니다. 고른 약을 다 먹은 날은 「다 먹은 날」 스티커가 붙고, 「이달 판 보기 ▼」를 누르면 이번 달 기록을 봅니다.

### 스티커 떼기

1. 잘못 눌렀으면 먹은 버튼을 한 번 더 누릅니다.
2. 「스티커 뗄까요?」가 나오면 「떼기」를 누릅니다. 그냥 두려면 「그대로」를 누릅니다.

떼는 것은 오늘 스티커만 됩니다.

기록은 쓰는 기기의 브라우저에 저장됩니다. 휴대폰과 컴퓨터에서 따로 쓰면 기록이 서로 보이지 않습니다. 같이 보려면 아래 「노션에 기록 연결하기」를 따라 하세요.

## 노션에 기록 연결하기(v1.1)

> 처음이라면 이 순서입니다: ① 노션 표 만들기 → ② 노션 통합 만들기 → ③ Vercel 버튼 누르기 → ④ 위젯에 주소 넣기. 모두 30분 안에 끝나고, 코드를 고칠 일은 없습니다.

연결하면 버튼을 누를 때마다 내 노션 표에 그날 기록이 한 줄로 남고, 다른 기기에서 위젯을 열면 그 기록을 받아 옵니다. 안 해도 위젯은 그대로 쓸 수 있습니다.

위젯은 노션에 직접 글을 쓸 수 없어서, 가운데에서 대신 전해 주는 작은 서버(중계 서버)를 하나 둡니다. 코드는 `medicine-relay/api/log.js` 파일 하나이고, Vercel 무료 요금제에 올려 씁니다.

### ① 노션에 표 만들기

노션에 새 표(데이터베이스)를 만들고 칸 이름을 아래와 똑같이 맞춥니다. 띄어쓰기까지 같아야 합니다.

| 칸 이름 | 종류 |
|---|---|
| 이름 | 제목 |
| 날짜 | 날짜 |
| 아침 | 텍스트 |
| 점심 | 텍스트 |
| 저녁 | 텍스트 |
| 자기 전 | 텍스트 |

아침·점심·저녁·자기 전 칸에는 약을 먹은 시각(예: 08:12)이 들어갑니다.

### ② 노션 통합 만들고 표에 연결하기

1. https://www.notion.so/profile/integrations 에서 「새 통합」을 만듭니다. 종류는 「내부」, 권한은 콘텐츠 읽기·수정·입력을 켭니다.
2. 만들어진 통합의 「시크릿」(토큰)을 복사해 둡니다. 비밀번호와 같으니 남에게 보여 주지 않습니다.
3. ①에서 만든 표 페이지를 열고 오른쪽 위 `⋯` → 「연결」에서 방금 만든 통합을 고릅니다. 이걸 해야 통합이 이 표를 읽고 쓸 수 있습니다.
4. 표 id를 적어 둡니다. 표를 전체 페이지로 열었을 때 주소에서 `?v=` 바로 앞에 있는 32글자(영문·숫자)입니다.

### ③ 중계 서버를 Vercel에 올리기 (버튼 한 번)

아래 버튼을 누르면 이 레포의 중계 서버가 내 Vercel에 복사되어 올라갑니다. 터미널은 필요 없습니다.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fgaebalhaetsyu%2Fnotion-yakmeogeotsyu-widget&root-directory=medicine-relay&env=NOTION_TOKEN,DATABASE_ID,KEY&envDescription=%EB%85%B8%EC%85%98%20%ED%86%A0%ED%81%B0%2C%20%ED%91%9C%20id%2C%20%EB%82%B4%EA%B0%80%20%EC%A0%95%ED%95%98%EB%8A%94%20%EC%95%94%ED%98%B8&project-name=my-yakmeogeotsyu)

1. 버튼을 누르고 Vercel에 로그인(가입)합니다. GitHub 계정으로 로그인하는 것이 가장 쉽습니다.
2. 「Create」를 누르면 값을 넣는 칸 3개가 나옵니다.

| 칸 | 넣을 값 |
|---|---|
| NOTION_TOKEN | ②에서 복사한 통합 시크릿 |
| DATABASE_ID | ②에서 적어 둔 표 id |
| KEY | 내가 정하는 암호(영문·숫자로 길게, 예: 아무 글자 20개) |

3. 「Deploy」를 누르고 1분쯤 기다리면 「Congratulations」 화면과 함께 내 주소(예: `my-yakmeogeotsyu.vercel.app`)가 나옵니다. 이 주소를 ④에서 씁니다.

### ④ 위젯에 주소 넣기

1. 위젯에서 「⏰ 약 시간 설정」을 누릅니다.
2. 「노션 연결 주소(선택)」 칸에 아래 모양으로 넣습니다.

```
https://<③에서 나온 내 주소>/api/log?key=<KEY에 넣은 암호>
```

3. 「저장」을 누릅니다. 설정을 다시 열었을 때 「노션과 연결됐어요.」가 보이면 된 것입니다. 이 기기에 있던 기록이 먼저 노션 표로 올라갑니다.
4. 다른 기기에서도 같은 주소를 넣으면 같은 기록이 보입니다.

### 알아 둘 것

- 이 주소에는 암호가 들어 있습니다. 주소를 아는 사람은 기록을 읽고 고칠 수 있으니 공개된 곳에 올리지 않습니다.
- 노션 연결이 안 될 때도 기록은 기기에 남고, 다음에 위젯을 열 때 다시 보냅니다.
- 연결한 뒤에는 최근 두 달 기록을 노션 표에 맞춥니다. 노션 표에서 시각을 고치거나 줄을 지우면 위젯에도 반영됩니다.
- 연결을 끊으려면 주소 칸을 비우고 「저장」을 누릅니다.

## 쓴 기술

- HTML·CSS·JavaScript 파일 하나(라이브러리 없음)
- localStorage 저장, GitHub Pages 배포, 노션 임베드
- (v1.1) 노션 연결: Vercel 함수 한 개(`medicine-relay/api/log.js`)가 노션 API로 표를 읽고 씁니다.
- 스티커 그림은 GPT로 만들었습니다.

## 디자인 이유

- 크림색과 주황색: 약 봉투와 스티커의 따뜻한 느낌을 냈습니다. 노션 안에서 따로 놀지 않도록 바깥 상자와 그림자 없이 흰 바탕에 그대로 놓았습니다.
- 밝은 화면만 있음: 만든 사람이 밝은 화면을 좋아하고, 노션도 밝은 화면에서 주로 씁니다.
- 큰 버튼(약이 3~4개면 2×2): 휴대폰에서 엄지로 바로 누르게 했습니다. 아직 안 먹은 버튼은 점선(스티커 붙일 자리), 먹으면 실선으로 바뀝니다.
- 「이달 판 보기 ▼」의 화살표: 접고 펴는 칸이라는 표시입니다.
- 글꼴 나눔스퀘어라운드: 스티커 판에 어울리는 둥근 글꼴 가운데, 휴대폰 작은 글자도 잘 읽히는 것으로 골랐습니다.
